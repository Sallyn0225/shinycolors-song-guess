# 结算 BGM、本地战绩统计、建房提示与空房回收

> 父任务。它自己**不承载实现**，只持有需求原文、任务图与跨子任务的验收口径。
> 四件事各自可独立实现、独立验收、独立归档。

## Goal

一次用户反馈里的四件事，共同点是「已经做完的那几屏，边角上还欠着一次交代」：

1. 单机结算页是全站唯一一块**该有氛围却哑着**的地方——从 Play 出来音乐没跟上来，回首页时又重头起一遍。
2. 玩了很多局的人，除了这一局的战报之外**什么都留不下**。没有最高分、没有「我总栽在哪个组合上」。
3. 公开房满了的时候，拒绝的话说给了一个**看不见**的地方——弹窗还开着，提示画在弹窗背后。
4. 两个人都走了的房间**还在**，还能被人加入，也还能被自己接回去，接回去的是一间没有对手的空房。

## 规划期已定的决策（用户确认，四个子任务共同遵守）

| 决策 | 取值 | 影响 |
|---|---|---|
| D1 · 统计面板形态 | **独立屏 `stats`**，不是弹窗 | `App.tsx` 的 `Screen` 联合类型多一支；返回首页要接回 BGM，与 U1 同一条改动 |
| D2 · 结算页背景 | **只加 BGM，不加背景视频** | BGM 的启停判断必须与「铺视频的那三屏」**解耦**，不能继续共用一个 `ambient` 布尔量 |
| D3 · 清房时机 | **房里一条活连接都不剩 → 立刻清** | 连带接受：单人等房时刷新页面，房间也立刻消失、重进要重新建房 |
| D4 · 统计维度 | 按组合正确率 + 按单曲正确率 + 最高/最低分与场次趋势 | 组合口径只计入 **8 个常设组合 + 全体曲（シャイニーカラーズ）**；shuffle unit 与无归属曲目不计入组合榜（仍计入单曲榜与总分） |
| D5 · 统计范围 | **只统计单机**，联机对局不计入 | 联机结算没有逐题的组合信息，是另一套统计，本轮不做 |

### 顺序约束（父/子结构本身不是依赖系统，顺序写在这里）

- **`result-bgm-continuity` 必须先于 `local-stats-trophy`**。前者要把 `App.tsx` 里那个既管视频
  又管 BGM 的 `ambient` 布尔量拆成两个判断；后者新增的 `stats` 屏只需要往拆好的 BGM 那一侧加一个名字。
  倒过来做，`stats` 屏会先落进一个「有 BGM 就必然有视频」的判断里，等前者再来拆一遍——同一处改两次。
- 其余三条互不相干，可任意顺序，也可并行。`abandoned-room-cleanup` 完全在服务端，与三条前端改动零重叠。

## 跨子任务验收标准

单个子任务的验收写在各自 PRD 里。以下是**只有把四件事放在一起才验得出来**的几条：

- [ ] **AC-P1 · 音乐在整条单机动线上只起一次**：首页 →（开局）Play → 结算 → 首页 → 奖杯屏 → 首页，
      全程 BGM 只在开局时淡出一次、在进结算时淡入一次；结算→首页、首页→奖杯屏、奖杯屏→首页
      三次切换听不到任何重起或断点。
- [ ] **AC-P2 · 背景视频的铺设范围没有被顺带改动**：视频仍然只出现在首页 / 大厅 / 房间三屏；
      结算页与新增的奖杯屏都没有视频（D2）。
- [ ] **AC-P3 · 大厅不再出现进不去的房间**：把公开房上限调到 1，建一间房后两人都断开，
      第二个浏览器刷新大厅——列表里立刻没有那间房，且「创建房间」可以成功
      （即 U3 的提示与 U4 的回收是同一个占用口径，不会出现「列表说满了、其实是幽灵房」）。
- [ ] **AC-P4 · 四件事都没动禁区**：`src/audio.ts` / `src/net/ws.ts` / `src/api.ts` / `src/features/*`
      的既有签名不变（见 `.trellis/spec/web/frontend/index.md` 的 The one rule that overrides taste）。
      `features/` 下**新增**纯逻辑文件是允许的，改既有文件不允许。
- [ ] **AC-P5 · 全仓绿**：`pnpm -r typecheck && pnpm -r lint && pnpm -r test`。

## Non-Goals

- 不做账号体系、不做服务端持久化。统计只落在**当前设备的 localStorage** 里，换设备/清缓存即失。
- 不做统计数据的导入导出、不做跨设备同步。
- 不统计联机对局（D5）。
- 不改任何计分规则、难度参数、房间配额的**默认值**。
- 不给结算页与奖杯屏加背景视频（D2）。
