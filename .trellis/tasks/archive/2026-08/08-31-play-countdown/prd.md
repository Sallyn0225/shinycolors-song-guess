# 单机开局 3-2-1 倒计时缓冲

## Goal

单机点击难度后直接开播起计时，用户无心理准备。在第一题开播前加 3-2-1 自动倒计时动画与配套倒计时音效，倒完开播 + 起计时。

## Dependencies

- **依赖 `08-31-ui-sfx` 已完成**：本任务的 tick / go 音效来自那边产出的 `sfx.ts` 音效层。若它未归档，本任务不得开始实施。

## Requirements

- R1 单机模式（Play 屏）**仅第一题**（index 0）在音频开播前进入「倒计时」阶段：大数字 3 → 2 → 1，每秒一格，之后开播 + 起计时。
  - 倒计时开始的前提是**题目已取到且切片已解码**（沿用现有 loading→answering 的中间插入点），慢网络下先等载入、再倒数，不把下载时间算进倒计时。
  - **`api.begin`（服务端起表）必须发生在倒计时结束之后**——计时公平性硬约束，现服务端语义已支持（begin 显式起表，`soloSessions.ts:121`），不改服务端。
  - 后续题（Enter/下一题）不加倒计时——节奏由玩家自己点「下一题」控制，已有缓冲。
- R2 倒计时视觉：居中大数字（latin，对齐 Countdown 的尺寸语言），每秒落地一次入场动画（缩放/淡入），`prefers-reduced-motion` 下只换数字不做动画。
- R3 倒计时音效：每秒一声 tick（`sfx.play('tick')`），结束时一声 go（`sfx.play('go')`）；静音时随 sfx 层静音。
- R4 错误与中断：倒计时期间退出本局照常可退（onQuit 不受影响）；倒计时阶段不响应答题键盘（1-4 无题可答，本来也不在 answering phase）。
- R5 1v1（Karuta）不在本任务范围。

## Acceptance Criteria

- [ ] 单机任一难度开局：先见载入（如网络慢）→ 3-2-1 倒计时动画 → 开播，全程无需再点击。
- [ ] 倒计时期间 PrismRail 光带显示满（未开始走表）；开播瞬间光带从满开始收拢。
- [ ] 倒计时每秒伴随 tick 音，开播前一声 go；`api.begin` 的网络往返不吞掉任何一格倒计时。
- [ ] reduced-motion 下数字仍每秒更换但无冲量动画。
- [ ] 退出本局 → 重新开局，倒计时行为一致（无残留计时器）。
- [ ] lint、type-check、现有测试全绿；`audio.ts` / `api.ts` / `net/ws.ts` / `features/*` 零改动。
